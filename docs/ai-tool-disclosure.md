# Legacy Migrate — AI & Tool Disclosure



## AI Provider



Legacy Migrate uses OpenRouter as the model gateway.



During development, the project used free models available through OpenRouter.

Because individual free models can become temporarily unavailable or rate-limited,

the application also supports the `openrouter/free` routing option.



The OpenRouter API key is loaded from a local `.env` file and is never committed

to the repository.



---



## Where AI Is Used



Legacy Migrate uses language models for the following tasks:



1. Legacy code refactoring

&#x20;  - Python 2 → Python 3

&#x20;  - Node.js callbacks → async/await



2. Refactoring explanations

&#x20;  - The model explains why major migration changes were made.



3. Unit-test generation

&#x20;  - The model generates executable test code for the refactored code.



4. Security commentary

&#x20;  - The model highlights potential security concerns associated with the code

&#x20;    or migration.



5. Migration Roadmap reasoning

&#x20;  - The model compares per-file migration results and helps propose a migration

&#x20;    priority order.



6. Risk commentary

&#x20;  - The model explains migration risks using dependency information supplied by

&#x20;    deterministic analysis.



---



## What Is NOT AI-Generated



The project deliberately separates AI judgment from deterministic information.



The repository dependency graph is not generated by the language model.



Import and `require()` relationships are extracted from source code using

deterministic parsing/regex logic.



This information is then used to calculate relationships such as:



- files a given file depends on

- files that depend on a given file

- migration blast radius



The AI receives this deterministic information as evidence when producing

roadmap and risk commentary.



---



## Human-in-the-Loop



Legacy Migrate is an advisory tool.



The AI does not automatically modify the user's repository or merge generated

code.



Generated refactors, tests, security commentary, confidence information, and

migration priorities must be reviewed by a developer before they are accepted.



A low-confidence or risky migration should be escalated for human review.



---



## Reliability and Failure Handling



The prototype explicitly handles external AI-service failures.



During development, OpenRouter free-tier limits produced HTTP 429 rate-limit

responses.



The backend surfaces these failures instead of silently treating them as valid

AI results.



For repository-mode processing, failure of one file is recorded independently

so that one failed AI request does not crash the complete batch operation.



---



## Data Handling



The prototype does not intentionally persist uploaded source code.



Code is processed during the application session for migration analysis and

generation.



API credentials are stored locally using environment variables / `.env` and

must never be committed to GitHub.



---



## Known Limitations



The current hackathon prototype has the following limitations:



- Repository refactors are performed independently per file.

- Cross-file dependency-aware code rewriting is not yet implemented.

- Dependency data provides visibility into cross-file impact, but does not

&#x20; automatically update dependent call sites.

- AI-generated tests and security commentary may contain mistakes and require

&#x20; human review.

- Availability and latency depend on the selected OpenRouter model/provider.

- Free-tier API rate limits can temporarily prevent live AI execution.

## Responsible AI Principle



Legacy Migrate follows a simple rule:



> AI proposes and explains; deterministic tools provide checkable evidence;

> humans make the final migration decision.
